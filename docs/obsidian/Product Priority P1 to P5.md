# Product priority P1 → P5

Canonical long-form: `docs/PRODUCT_PRIORITY.md`.

## P1 — Web app (now)

**Goal:** wetdrool.com feels like an app the second you land.

Done / in motion:

- Entry → `/hub`
- Shorts, live, creators, token, mesh pages
- Points ledger (device-local)
- NSFW 18+ self-attest
- `$DROOL` tax config (mint-pending)

Still open:

- Durable product API + UI fully on `/api/v1`
- Real media + live SFU
- Ads → points ceiling automation

## P2 — Web3 dApp

Wallet connect, message sign, optional `$DROOL` when CA is pasted into env + deployments, settlement without rebroadcast lies.

## P3 — Seeker (SKR)

`apps/mobile`, MWA, dApp Store portal. Device hint is not entitlement.

## P4 — Android

General Play / sideload after Seeker path is stable.

## P5 — iPhone

Expo iOS + App Store review. Explicitly **not** claimed live.

## Dependency rule

Never block P1 on P3–P5. Never claim P2 mint before CA exists.
