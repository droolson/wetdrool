# Product formula

WetDrool is **one web app** that composes familiar adult + social patterns without copying their centralization:

| Inspiration | WetDrool surface | Behavior |
| ----------- | ---------------- | -------- |
| **RedGIFs** | `/feeds` shorts | Vertical cards, mode chips, watch → points |
| **Pornhub / RedTube** | `/hub` | Category chips, dense tile grid, browse-first |
| **Twitch (18+)** | `/live` | Room cards, NSFW gate, tips staged |
| **OnlyFans** | `/creator/[id]` | Sub / PPV / tip / live ticket, E2EE delivery target |
| **Reddit** | points + communities | Cap-aware points, directory later |
| **X** | `/home` + `/compose` | Timeline + composer |

## What is deliberately *not* the product

- Marketing-only landing with “Join the beta” as the only CTA  
- Scraped third-party porn APIs without license + consent + age records  
- Fake viewer counts, fake tips, fake mint price charts  

## Current media honesty

All short/hub fixtures are **synthetic abstract gradients** labeled `synthetic: true` / `contentWarning: abstract-only` until a verified media pipeline (CAS + ClamAV + consent ledger) is online.
