About this onion gateway

WetDrool is an 18+ social / media product. This site is a Tor-optimized, script-free gateway for sealed rooms.

CSP blocks all scripts. Styles and media are same-origin only. No third-party fonts, analytics, or CDNs.

Tor setup (operator)

See apps/onion/torrc.example in the monorepo. Point HiddenServicePort 80 to this origin (local or Vercel).
